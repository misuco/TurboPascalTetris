Help

How to Play

Arrow Keys Left/Right: Move the falling stone left or right

Arrow Key Down: Drop the stone faster (gain bonus points)

Space Bar: Rotate the current stone

P: Pause or resume the game

ESC: Quit the current game

Scoring

Complete horizontal lines to clear them and earn points.

Bonus points awarded for dropping stones quickly.

Game speeds up as you progress through levels.
